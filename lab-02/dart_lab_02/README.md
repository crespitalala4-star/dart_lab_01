# Lab 02 - Dart: Control Flow, Loops and Validated Input

## Descripción
Programa de consola en Dart para registrar observaciones agrícolas y venta de entradas de cine, con validación de entrada, menús con `while`, `switch`, `for` y funciones reutilizables.

## Archivos en `bin/`
- `agricultural_explorer.dart` - Programa principal: registra municipio, año, cultivos, calcula total, promedio, mayor cultivo y su porcentaje.
- `cinema_ticket_sales.dart` - Reto: venta de entradas con capacidad 40, General $18000, Estudiante $12000, control de aforo e ingresos.
- `practice_21.dart` - Comparaciones, booleanos, `&&`, `||`, `!`.
- `practice_22.dart` - `if / else if / else` y clasificación de participación.
- `practice_23.dart` - `switch` y menús.
- `practice_24.dart` - `for`, acumuladores, `break` y `continue`.
- `practice_25.dart` - Validación con `tryParse`, funciones `readRequiredText`, `readIntInRange`, `readPositiveArea`.

## Cómo ejecutar
```bash
dart run bin/agricultural_explorer.dart
dart run bin/cinema_ticket_sales.dart
dart run bin/practice_21.dart
dart run bin/practice_22.dart
dart run bin/practice_23.dart
dart run bin/practice_24.dart
dart run bin/practice_25.dart
